# Директория для изображений

Поместите сюда приветственное изображение с именем `welcome.jpg`.

## Требования к изображению

- Формат: JPG, PNG
- Рекомендуемый размер: 1280x720 или 1920x1080
- Максимальный размер файла: 10MB (ограничение Telegram)

## Как добавить изображение

1. Скопируйте ваше изображение в эту директорию
2. Переименуйте его в `welcome.jpg` или измените путь в `.env` файле

```bash
cp /path/to/your/image.jpg images/welcome.jpg
```

Если вы хотите использовать другое имя файла, отредактируйте `.env`:

```
WELCOME_IMAGE=images/your_image_name.jpg
```
