# Настройка бота

## Как изменить ссылки и сообщения

Все настройки бота находятся в файле `bot.py`. Откройте его в любом текстовом редакторе.

### Изменение приветственного сообщения

Найдите переменную `WELCOME_MESSAGE` (примерно строка 50):

```python
WELCOME_MESSAGE = """
👋 Добро пожаловать!

Я ваш личный помощник. Нажмите кнопку "Старт" чтобы перейти в главное меню.
"""
```

Измените текст на свой.

### Изменение сообщения главного меню

Найдите переменную `MAIN_MENU_MESSAGE` (примерно строка 56):

```python
MAIN_MENU_MESSAGE = """
📋 Главное меню

Выберите интересующий вас раздел:
"""
```

### Изменение пунктов меню и ссылок

Найдите словарь `MENU_ITEMS` (примерно строка 30). Здесь находятся все пункты меню:

```python
MENU_ITEMS = {
    'news': {
        'title': '📰 Новости',
        'message': '🗞 Добро пожаловать в раздел новостей!\n\nЗдесь вы найдете самые свежие и актуальные новости.',
        'links': [
            {'text': '🔗 Канал новостей', 'url': 'https://t.me/example_news'},
            {'text': '🌐 Новостной портал', 'url': 'https://example.com/news'}
        ]
    },
    ...
}
```

#### Для изменения существующего пункта:

1. Найдите нужный раздел (news, movies, sport)
2. Измените `title` - название кнопки в меню
3. Измените `message` - сообщение при открытии раздела
4. Измените `links` - ссылки на каналы и ресурсы

**Пример изменения ссылок для раздела "Новости":**

```python
'news': {
    'title': '📰 Новости',
    'message': '🗞 Добро пожаловать в раздел новостей!\n\nЗдесь самые свежие новости!',
    'links': [
        {'text': '📢 Наш новостной канал', 'url': 'https://t.me/your_channel'},
        {'text': '🌐 Наш сайт', 'url': 'https://yoursite.com'},
        {'text': '📱 Наша группа', 'url': 'https://t.me/your_group'}
    ]
},
```

#### Для добавления нового пункта меню:

Добавьте новый раздел в словарь `MENU_ITEMS`:

```python
MENU_ITEMS = {
    'news': { ... },
    'movies': { ... },
    'sport': { ... },
    # Добавьте новый пункт:
    'gaming': {
        'title': '🎮 Игры',
        'message': '🕹 Добро пожаловать в игровой раздел!\n\nЗдесь все об играх.',
        'links': [
            {'text': '🎮 Игровой канал', 'url': 'https://t.me/gaming_channel'},
            {'text': '🌐 Игровой портал', 'url': 'https://gaming.com'}
        ]
    }
}
```

**Важно:** Ключ раздела (`gaming` в примере) должен быть уникальным и состоять из латинских букв.

### После изменений

1. Сохраните файл `bot.py`
2. Если бот работает локально, перезапустите его: `Ctrl+C` и снова `python bot.py`
3. Если бот на сервере, выполните:
   ```bash
   cd /telebot
   git pull origin main
   sudo systemctl restart telebot
   ```

## Изменение токена бота

Токен бота хранится в файле `.env`:

```bash
BOT_TOKEN=ваш_новый_токен
```

После изменения перезапустите бота.

## Изменение приветственного изображения

1. Поместите новое изображение в папку `images/`
2. Либо назовите его `welcome.jpg`, либо измените путь в `.env`:
   ```bash
   WELCOME_IMAGE=images/новое_имя.jpg
   ```
3. Перезапустите бота

## Проверка изменений

После внесения изменений всегда проверяйте работу бота:

1. Отправьте команду `/start` боту
2. Проверьте, что все кнопки работают
3. Проверьте, что ссылки ведут на правильные ресурсы
